# 🎮 五子棋 · 局域网联机

一个基于 **Node.js + Socket.io** 的局域网联机五子棋游戏。一台电脑运行服务器，同一局域网内的其他设备用浏览器连接即可对战。

---

## 📁 项目结构

```
gomoku/
├── server.js           ← 联机服务器（Express + Socket.io）
├── package.json        ← 项目配置与依赖
├── public/
│   └── index.html      ← 前端页面（Canvas 绘制棋盘）
├── README.md           ← 本文件
└── node_modules/       ← 依赖包（npm install 后自动生成）
```

## 🚀 快速开始

### 第一步：安装依赖

确保电脑已安装 [Node.js](https://nodejs.org/)（版本 ≥ 16），然后在项目目录下运行：

```bash
npm install
```

### 第二步：启动服务器

```bash
npm start
```

启动后会显示：

```
╔══════════════════════════════════════╗
║       🎮 五子棋 联机服务器已启动      ║
╠══════════════════════════════════════╣
║  主机访问: http://localhost:3456      ║
║  客机访问: http://192.168.x.x:3456   ║
║                                      ║
║  把客机地址发给同一局域网的对手即可    ║
╚══════════════════════════════════════╝
```

### 第三步：双方打开浏览器

| 玩家 | 访问地址 | 说明 |
|------|----------|------|
| 主机 | `http://localhost:3456` | 运行服务器的这台电脑 |
| 客机 | `http://<主机IP>:3456` | 同一局域网内其他设备 |

> **先连入的玩家自动成为黑方 ⚫（先手），后连入的成为白方 ⚪（后手）。**

### 第四步：开始对战！

- ✅ 绿色状态点 + "👈 轮到你了" = 可以落子
- ⏳ "等待对手落子..." = 对方正在思考
- 🔴 红色小点标记最后一手落子位置
- 🏆 五连珠自动判定胜负
- 🔄 点击「重新开始」换边再战
- 📋 点击「复制链接」把地址发给对手

## 🎯 功能特性

| 功能 | 说明 |
|------|------|
| 🌐 **局域网联机** | WebSocket 实时通信，延迟极低 |
| 🪪 **自动分配角色** | 先连=黑方、后连=白方，无需手动选择 |

| 👻 **悬停预览** | 鼠标悬停显示半透明棋子，只有自己的回合才显示 |
| 🔴 **最后落子标记** | 红色圆点标注，方便追踪对手落子 |
| 📋 **一键分享** | 复制房间链接，方便发给对手 |
| 🔌 **断线提示** | 对手离开时自动通知，重置等待新玩家 |

## 🖥️ 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| **运行时** | Node.js | 服务器运行环境 |

**零前端构建工具、零数据库、零配置**——一个文件夹，两条命令就能玩。

## 📡 通信协议

游戏通过 Socket.io 实现实时双向通信，以下是完整的事件协议：

### 客户端 → 服务器

| 事件 | 载荷 | 说明 |
|------|------|------|
| `join` | 无 | 请求加入房间 |
| `move` | `{ row: number, col: number }` | 在指定坐标落子 |
| `reset` | 无 | 请求重新开始游戏 |

### 服务器 → 客户端

| 事件 | 载荷 | 说明 |
|------|------|------|
| `roomStatus` | `{ status, yourColor, yourName, message, board, currentTurn, gameOver, winner }` | 房间状态变更（等待/就绪/满员） |
| `moveConfirmed` | `{ row, col, player }` | 落子成功，双方同步棋盘 |
| `gameOver` | `{ winner, winnerName }` | 游戏结束（winner=0 为平局） |
| `moveError` | `{ message }` | 落子被拒绝及原因 |
| `resetConfirmed` | `{ board, currentTurn, message }` | 游戏已重置 |
| `playerLeft` | `{ message }` | 对手断开连接 |

## 🔧 自定义配置

### 修改端口

编辑 [server.js](server.js) 最后一行：

```js
const PORT = 3456;   // 改成你想要的端口号
```

### 修改棋盘大小

编辑 [public/index.html](public/index.html) 顶部常量：

```js
const BOARD_SIZE = 15;   // 棋盘线数（默认 15）
const CELL_SIZE = 36;    // 每格像素大小
```

### 修改胜利条件

编辑 [server.js](server.js)：

```js
const WIN_COUNT = 5;     // 默认五连珠，可改为 4 或 6
```

## 🐛 常见问题

### Q: 端口被占用怎么办？

修改 [server.js](server.js) 中的 `PORT` 为其他值（如 `9527`、`8080`）。

### Q: 客机连不上服务器？

1. 确认双方在同一局域网（连同一个 WiFi）
2. 检查主机防火墙是否阻止了端口（Windows 防火墙会弹窗询问，点"允许"即可）
3. 服务器启动时会打印局域网 IP，确认客机用的是这个 IP

### Q: 第三个人能加入吗？

不能。房间限制 2 人。第三人打开页面会看到"房间已满"提示。

### Q: 对手断开后怎么办？

剩余玩家自动转为黑方，等待新对手加入。之前的游戏状态会重置。

### Q: 只有一台电脑怎么测试？

开两个浏览器窗口，都访问 `http://localhost:3456`。第一个窗口是黑方，第二个是白方。
